## About

Deadsmile Games Launcher is built with **C#, WinUI 3, and XAML** for Windows. The release package is **MSIX only**; the project does not publish EXE or MSI installers.

- **Version:** 1.0.1
- **Platform:** Windows x64
- **UI:** Native WinUI 3
- **Distribution:** MSIX
- **Build and validation:** GitHub Actions

## Installation

Get the latest available package from [GitHub Releases](https://github.com/deadsmilegames/launcher/releases/latest). A development MSIX generated by CI is intended for validation and may use a development certificate. It is not a production Store-signed package.

For Microsoft Store distribution, submit the production MSIX through Partner Center. Microsoft signs the package after Store certification; do not treat an unsigned submission package as ready for general installation.

## Development

The Windows project and build instructions are in [winui/](winui/) and [winui/README.md](winui/README.md). GitHub Actions runs automated tests and validates MSIX installation and startup on a Windows runner.

Only the MSIX package is published as the installable artifact. EXE and DLL files produced during the build are internal app components, not separate installers.
