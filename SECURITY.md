# Security policy

The launcher handles account sessions, game downloads, cloud saves, and local installation data.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in public issues, pull requests, discussions, or social media. Email **deadsmilegames@gmail.com** with the subject `Security vulnerability — Windows launcher`.

Include the affected component, Windows version, reproducible steps, expected and observed behavior, and a proof of concept that can be shared safely. Never include real credentials, session cookies, access tokens, personal data, encryption keys, or production data.

Please allow the maintainers reasonable time to investigate before public disclosure. Do not access, modify, or delete data that does not belong to you.
